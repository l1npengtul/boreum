# Boreum Lang Doc V2

Boreum is a language that is a cursed marriage of Lua, Rust, Elixir, and Clojure. It is designed to 
target WASM/WASI(wasmtime specifically), and to be easily interoperable with other WASM languages and Rust.

Boreum is a strong, duck typed language with optional but encouraged static typing with compositional types.

Boreum comes from a shortening of the Korean word `보름달`(boreumdal), which means "full moon".

`Strings` are strings that can have formatting values inside of them. Their partials (aka the parts in between the formatting)

Literal Constants.

### 2.2 Identifiers

```
Allowed    ::= [_a-zA-Z]

SimpleIdentifier ::= Allowed (Allowed | [0-9] | '-')?
PathPrefix       ::= ( SimpleIdentifier '/' )*? SimpleIdentifier
FieldIdentifier  ::= PathPrefix ( ( RawFieldCall | FieldCall ) SimpleIdentifier )?
PathIdentifier   ::= PathPrefix ( RawFieldCall SimpleIdentifier )?
```

An identifier is any alphanumeric that is not a reserved keyword and starts with either a `_` or alphabetical character.

`SimpleIdentifier` is used during declerations (e.g. variable, functions, etc.)
`FieldIdentiffer` is used in expressions.
`PathIdentifier` is used when an absolute path of an item is needed, e.g. import. or during Function calls. 

Variables, Functions, Fields, and Modules should be in `snake_case`, 
while Type Identifiers and Enum Cases should be in `PascalCase`.

## 3.0 Memory Model 

The Boreum Memory Model follows a slightly modified version the Dala Memory Model outlined in https://arxiv.org/abs/2109.07541v1.

Each pointer/reference has a capability assigned to it at creation time, it being either
- Immutable: The reference can be shared freely, but no modifications may be made after creation.
- Isolated: The reference may be sent between fibres but may not be aliased.
- Local: The reference may be freely aliased but may not be dereferenced by other fibres.
- Unsafe: The reference has no restrictions, and may interact and reference any other reference on the safe heap. 
It is the programmer's duty to ensure correctness of `unsafe` references.
- Rust: This reference is from Rust, and is therefore blazingly fast :fire:. It exists to simplify interop between Boreum and Rust. 
Note that this reference type has subtypes, corresponding to each of Rust's pointer types.
- Alias: This reference is specifically a self-referential reference, created within a table when a composition occurs to allow 
for cascaded values to be shadowed. 

Functions can specify which capability a reference requires by prefixing the argument with one of the capabilities.

## 4.0 Base Data Structures

There are 5 primary data structures within Boreum:
- Figment: Value type `struct`s. They allow a programmer to opt-out of Boreum's table based model, and map directly to WASM `struct`s.

bases of Composition.
- Enum: Tagged Unions. These are also Value types.
- List: A List of values. These are heterogenous.
- Array: Homogenous Lists

### 5.1 Compositional Types

Compositional Types are types created by using the Sakana composition operators. The new type has properties of both the
base type and the composed type. For example, a fish can be described as a composition of the Flipper, WaterBreathing,
and Animal types. Therefore, the Fish type would have the
- Primary type of `Fish`.
- Secondary composed types of `Animal`, `WaterBreathing`, and `Flipper`.

In this way, when `Fish` is passed to a function that expects `Animal`, the value is automatically constrained so that
the function believes it is getting an `Animal`, and only an `Animal`, but in reality is handling a `Fish`.

## 8.0 Concurrency

Boreum does its concurrency exclusively via nurseries. A nursery has a number of child fibres that 
cooperatively yield back to the runtime scheduler. The nursery is responsible for being the "parent" of all child fibres,
it also must manage message passing between its child nodes and run appropriate cleanup and handling when a fibre
exits or dies/is killed.

## 9.0 Capabilities

Capabilities represent what a function or module may do. These represent side effects - such as network or filesystem 
access. These capabilities are enforced at runtime, as static validation of capabilities would be much too slow and impossible
to perform statically. When a function or block attempts to perform an action that is prohibited, the runtime shall panic.

## 10.0 Playing Nice

Boreum can import any function, interface, or type from an external `.wit` file. The entirety of WASM types is supported
within Boreum, with `struct`s mapping directly to `figment`s, etc...
